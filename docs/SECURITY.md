# Security policy

Melampo is research software; no version is supported for clinical use.

**Reporting a vulnerability:** do not open a public issue. Use GitHub's private vulnerability reporting (the
"Report a vulnerability" button in the Security tab) or write to the project lead (see the root README).

**Never include patients' data, report texts or credentials in a report.**

*To be completed: response times, supported versions, coordinated disclosure.*
