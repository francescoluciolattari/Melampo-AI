# Copie dei file CIPI e della transcodifica ICD-9-CM → CIPI

Il workflow `classifications-it` mette qui i file scaricati dal Ministero della Salute (licenza CIPI confermata,
14 ottobre 2026). Li usa quando il sito non si lascia scaricare (verifica del browser) e in quel caso lo dice:
la ricerca di una versione nuova, per quel file, non è stata fatta.

Se anche il browser del workflow non passa la verifica, i file si scaricano a mano dalla pagina
https://www.salute.gov.it/new/it/tema/assistenza-ospedaliera-sdo/la-classificazione-delle-procedure-cipi/
e si mettono qui con lo stesso nome (per esempio `6.TAB_CIPI_V.GAMMA_2.0.xlsx`,
`7.TRANSCOD_ICD-9-CM-CIPI_V.GAMMA_2.0.xlsx`).
